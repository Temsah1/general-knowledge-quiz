# 🧠 General Knowledge Quiz App

A simple interactive **Python console-based quiz game** that tests general knowledge across multiple topics like science, geography, history, and math.
The project is designed to demonstrate basic programming concepts such as functions, loops, lists, randomization, and user interaction.

---

## 🚀 Features

* 🎯 Randomly selected questions each game session
* ⌨️ Interactive command-line interface
* 💡 Hint system for each question
* 📊 Instant scoring system
* 🏁 Final performance evaluation
* 🔁 Option to replay the quiz
* 🧠 30+ general knowledge questions

---

## 🛠️ Built With

* Python 3.x
* Standard Libraries:

  * `random`
  * `time`

## 🎮 How It Works

* The game randomly selects **3 questions per round**
* User inputs answers in the terminal
* Each correct answer = **+1 point**
* At the end, the system shows:

  * Final score
  * Performance message

---

## 📊 Scoring System

* 100% → Perfect score — outstanding work!
* 67%+ → Great job — almost perfect
* 34%+ → Good effort — keep practising
* Below → Don't give up — review and retry!
